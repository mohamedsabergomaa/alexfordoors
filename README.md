# Alexandria for Doors

موقع عربي RTL قابل للاستبدال والتطوير للشركة، مبني بـ Vite + React + TypeScript.

## التشغيل

```bash
npm install
npm run dev
```

لبناء نسخة الإنتاج:

```bash
npm run build
npm run preview
```

## أين أغيّر بيانات الشركة؟

كل بيانات التواصل في ملف واحد:

```text
src/config/site.ts
```

- `whatsappNumber`: أرقام فقط مع رمز الدولة، دون `+` أو مسافات. مثال: `201234567890`.
- `phoneNumber` و`phoneHref`: كما ستعرضها الشركة.
- `address` و`email` و`mapsEmbedUrl` وروابط السوشيال.

قبل إدخال رقم واتساب حقيقي، تفتح كل أزرار واتساب صفحة التواصل بدل رابط معطل. بعد إدخال الرقم، تتحول تلقائيًا إلى `wa.me` برسالة عربية جاهزة تتضمن اسم المنتج عند الحاجة.

## أين أعدّل المحتوى؟

| الملف | المحتوى |
|---|---|
| `src/data/categories.ts` | فئات الأبواب |
| `src/data/products.ts` | المنتجات والمواصفات والخامات والتشطيبات |
| `src/data/services.ts` | الخدمات الأربع |
| `src/data/home.ts` | نصوص الهيرو والمقدمة ولماذا نحن |
| `src/data/projects.ts` | مشاريع الشركة — فارغ عن قصد حتى تُرفع صور حقيقية |
| `src/data/navigation.ts` | روابط التنقل |

لا توجد أسعار لأن الشركة لم تزوّدنا بأسعار معتمدة.

## الصور

- الصور التوضيحية محفوظة في `public/images/`.
- مصادرها وترخيصها موثّق في `public/images/SOURCES.md`.
- المسارات المركزية في `src/data/images.ts`.
- لاستبدال صورة، ضع الملف بنفس الاسم أو عدّل المسار والـ alt في ملف البيانات المرتبط.

## ملاحظات نشر

- أضفنا `public/_redirects` و`public/vercel.json` لدعم فتح روابط المنتجات مباشرة.
- لا تظهر مشاريع في صفحة «أعمالنا» حتى تُضاف صور حقيقية من الشركة.
- النموذج لا يملك باكند؛ يتحقق من الإدخال ثم يفتح واتساب برسالة جاهزة.
